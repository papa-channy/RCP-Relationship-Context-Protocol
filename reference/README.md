# Reference Implementation

This directory will contain the RCP reference implementation.

Planned components:

- `rcp-core`
- `permission-engine`
- `policy-engine`
- `identity-engine`
- `provenance-engine`
- `secure-envelope`
- five independent mock providers
- one relationship consumer

The reference implementation must remain subordinate to the specification. It is an example implementation, not the definition of RCP.
