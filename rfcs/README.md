# RCP RFCs

RCP does not yet operate a formal RFC process. This directory reserves the format for substantial protocol changes once external participation begins.

A future RFC should include:

1. Summary
2. Motivation
3. Actors and resources affected
4. Protocol semantics
5. Security and privacy impact
6. Rights/policy impact
7. Backwards compatibility
8. Positive examples
9. Negative/adversarial examples
10. Alternatives considered
